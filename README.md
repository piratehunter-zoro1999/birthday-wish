# 💖 Premium Interactive Birthday Website

A local, no-backend romantic birthday experience built with HTML5, CSS3 and vanilla JavaScript.

## Run it

1. Open the `assets` folder.
2. Add your files:
   - `music.mp3`
   - `memory1.jpg` through `memory6.jpg`
3. Open `index.html` in a modern browser.

No npm, React, backend or database is required.

## Personalize it

Open `script.js` and edit the `CONFIG` object at the top:

- `herName`
- `yourName`
- `date`
- `ourFirstMemory`
- `ourSpecialDate`
- `insideJoke`
- `favoriteMemory`
- `personalMessage`
- `birthdayMessage`
- `musicFile`
- `memories`
- `reasons`

You only need to edit these values; the rest of the JavaScript uses them automatically.

## Photos

Replace:
- `assets/memory1.jpg`
- `assets/memory2.jpg`
- `assets/memory3.jpg`
- `assets/memory4.jpg`
- `assets/memory5.jpg`
- `assets/memory6.jpg`

You can also change each caption inside `CONFIG.memories`.

## Music

Put your chosen song at:

`assets/music.mp3`

Music never starts automatically. The user must tap the Sound button, as required by browser autoplay policies.

Replace the placeholders with real details rather than generic text. The biggest emotional upgrade will come from:
1. Real photos
2. One very specific inside joke
3. A first-memory detail
4. A message written in your own words
5. A song that has meaning for both of you
